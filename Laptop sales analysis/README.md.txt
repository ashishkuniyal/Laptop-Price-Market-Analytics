# 💻 Laptop Market Analysis Dashboard

An end-to-end Data Analytics project that analyzes laptop market data using Python and Power BI.

The project covers:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Interactive Dashboard Development
- Business Insights

# 📌 Business Insights

- MSI generated the highest overall sales.
- Gaming & Design laptops contribute the highest revenue.
- Average laptop price increases with RAM capacity.
- FreeDOS and Linux account for a significant share of operating systems.
- RTX-series GPUs are among the most common high-performance GPU options.
